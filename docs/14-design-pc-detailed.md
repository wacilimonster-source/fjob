版本 1.1 · 2026-11-10 · 状态：**设计交付；交互原型已实现；决策已确认；生产未实施**。任务编号 **M9-PC**，细化 `docs/13-design-pc-companion.md` 的产品方案。

关联材料：`docs/01`、`docs/02`、`docs/04`、`docs/12`、`docs/13`、`contracts/widget-snapshot-v2.schema.json`、`prototype/pc.html`。金额、时间、完整性和隐私口径继续以 `docs/04` 与 `docs/12` 为准，本文不另立算法。

## 0. 本次交付

本文把方案稿落成可评审、可开发的页面级设计：

- **可点击原型**：`prototype/pc.html`，含主窗、固定窗 S/M/L、配置管理、数据页、设置页、导入导出弹窗、固定窗引导和首次启动入口。
- **页面规格**：窗口尺寸、栅格、组件、状态、文案、键盘与失败行为。
- **验收用例**：PC-D01–PC-D22，标注哪些已在原型中走查、哪些必须在真实 Windows 应用验证。
- **实现边界**：哪些是原型模拟，哪些必须由 `finance_core`、Windows 原生窗口和行情网关提供。

原型是**设计参照**，不是生产实现：时钟、报价、基金净值、导入导出和更新检查均为模拟；刷新页面即重置，不写任何本地数据。

用 Chrome 或 Edge 打开 `prototype/pc.html`。推荐视口 **1440 × 900**；已检查 **1280 × 800** 和 **1180 × 720**，三档均无横向溢出。页面不依赖外部字体、图片或网络请求，可离线打开。

## 2. 设计口径与关键决策

### 2.1 同源，不另算

PC 端固定窗和主窗的所有金额、时间、完整性必须来自同一份 `DashboardSnapshot` 与 `WorkSessionContext`。PC 不重新实现工资、分摊或盈亏算法；`finance_core` 继续消费 `fixtures/calculation-cases.json`。原型中的金额只用于演示布局。

### 2.2 与方案稿的尺寸差异

| 部件 | 方案稿 | 详细设计/原型 | 原因 |
| --- | --- | --- | --- |
| M 便签卡 | 320 × 188 | **320 × 220** | 188 放不下 40 px 倒计时 + 明细 + 计薪进度 + 34 px 金额 + 报价时间；220 实测可完整显示，不裁切 |
| L 工位窗 | 420 × 300 | **420 × 390** | 需要 112 px 紧凑场景 + 34 px 分项条；300 会挤压金额或场景 |
| S 数字条 | 220 × 76 | 220 × 76 | 不变 |
| 固定窗默认位置 | 右下角 | 右下角，距右 28、距任务栏 22 | 不遮任务栏，靠近屏幕边缘但不贴死 |

M/L 的增高只影响固定窗，不改变主窗布局；如果后续坚持 188/300，必须删减“报价时间”或“L 分项条”，不能缩小系统字体硬塞。

### 2.3 PC 专属决策

1. **金额隐身只作用于固定窗、配置预览、托盘提示、窗口标题和固定窗无障碍文案。** 主窗是用户主动打开的安全区，金额继续可见；这与手机“小部件隐藏金额、App 内可见”的分工一致。若未来要“主窗也隐身”，作为独立开关，不复用同一语义。
2. **固定窗默认置顶但不抢焦点**；全屏应用自动隐藏；关闭固定窗只是隐藏到托盘，不是退出。
3. **资产页收起右侧预览面板**，把宽度让给持仓表；浮动固定窗仍在桌面上，继续承担实时预览。
4. **同一时间只有一个主窗**；固定窗和主窗是两个顶层窗口，技术实现必须先做 PC0 多窗口验证。
5. **固定浅色纸感**；深色桌面只提供“夜间降亮”，不做深色主题。
6. **角色、房车、办公室、硬币、拍肩/离场动效必须复用手机端 Dart painter/controller/palette/motion。** 不复制 `prototype/pc.html` 的 Canvas JS，不使用截图或关键帧作为生产素材。详细复用矩阵见 `docs/15-handoff-pc-implementation.md`。

## 3. 全局视觉与布局

### 3.1 桌面画布

| 项目 | 规格 |
| --- | --- |
| 基准画布 | 1440 × 900；最小 1180 × 720 |
| 任务栏 | 高 46 px，半透明奶油纸面，位于底部 |
| 主窗默认位置 | 1440 宽时 `left 64, top 54`；1280/1180 时 `left 40` |
| 主窗默认尺寸 | 1440：1000 × 680；1280：880 × 670；1180：780 × 590 |
| 固定窗 | 绝对定位，默认右下角；M 320 × 220 |
| 层级 | 固定窗 40（未置顶 15）< 任务栏 50 < 演示面板 70 < 菜单 95 < 弹窗 100 < toast 120 |

主窗关闭时隐藏到托盘；固定窗独立保留。主窗不抢固定窗焦点，固定窗也不抢当前文档焦点。

### 3.2 颜色

| Token | 值 | 用途 |
| --- | --- | --- |
| paper | `#F7F2E9` | 主窗底色、固定窗外层 |
| panel | `#FFFDF7` | 卡片、表单、表格纸面 |
| ink | `#323A32` | 文字、轮廓、主按钮 |
| muted | `#686E61` | 辅助文字 |
| line | `#D5D6C8` | 分隔、细边 |
| soft | `#E9EDDF` | 选中底色、办公室墙面 |
| yellow | `#F2DFAC` | 时间卡、便签、灯光 |
| rose | `#F0D2C5` | 椅子、小车、房顶 |
| negative | `#AD4736` | 负值、错误、危险操作 |
| positive | `#46644E` | 正值、成功、开关开启 |

固定浅色：不跟随系统深色，不提供主题切换。大数字、负号、金额精度不能只靠颜色区分，必须同时有文字状态。

### 3.3 字体与字号

| 场景 | 字号/字重 | 说明 |
| --- | --- | --- |
| 主窗正文 | 10–12 px / 400 | `Microsoft YaHei UI` |
| 主窗页面标题 | 22 px / 700 | 字距 -0.5 px |
| 主窗指标数字 | 40 px / 800 | 等宽数字，`tabular-nums` |
| 主窗结余数字 | 34 px / 800 | 同上 |
| 固定窗倒计时 | 40 px / 800 | 等宽；S 档 21 px |
| 固定窗结余 | 34 px / 800 | S 档 18 px |
| 卡片标签/说明 | 9–10 px | 说明单行截断，完整值进无障碍文案 |
| 按钮/表格 | 10–11 px | 关键按钮最小高度 30 px |

字体优先系统字体；如需跨机器一致的等宽数字，捆绑 OFL 授权字体并在关于页列出许可。

### 3.4 间距、圆角与阴影

- 4 px 基础栅格；主窗内容内边距 20–22 px；卡片内边距 13–16 px。
- 主窗圆角 18/14/17/13 px；固定窗 16/18/14/17 px；表单/卡片 10–13 px。
- 轮廓 1.5 px；角色和场景主线 2 px；图标 1.5–1.7 px。
- 纸影：`0 2px 0 rgba(50,58,50,.05)` 加低对比大阴影；固定窗使用 `0 18px 36px`，不夸张。
- 允许极轻微不规则边缘，但由确定性参数生成，不每帧随机抖动。

### 3.5 动效

| 场景 | 时长 | 说明 |
| --- | --- | --- |
| 主窗出现 | 450 ms | 8 px 上移 + 轻微缩放 |
| 页面切换 | 220 ms | 3 px 上移淡入 |
| 固定窗密度切换 | 180 ms | 宽高过渡，位置按最近边缘锚定 |
| 进度条 | 250 ms | 只随快照变化 |
| 弹窗 | 200 ms | 6 px 上移 |
| 倒计时 | 无动画 | 秒数直接替换，避免数字抖动 |
| 角色 | 2 Hz 打字、4 s 呼吸 | 低动效时静态 |

`prefers-reduced-motion` 或用户开启“减少动效”时，全部循环动画停止；数字仍然更新。

### 3.6 键盘与焦点

- Tab 顺序：标题栏 → 左侧导航 → 页面内容 → 固定窗（若聚焦）。
- 按钮、开关、单选项、输入框有 2 px 绿色焦点环，偏移 2 px。
- `Esc` 关闭菜单/弹窗；`Enter` 在表单内提交；`Ctrl+S` 保存配置（实现时补）。
- 固定窗不进入任务栏；`Alt+Tab` 不应出现固定窗缩略图。
- 倒计时和金额不逐秒自动播报；用户聚焦时由 Narrator 读取当前完整语义。

### 4.3 今日页

#### 布局

```text
页面标题（今日 / 日期时间 / 在岗印章 / 手动刷新）
┌─────────────────────────┬─────────────────────────┐
│ 时间卡                   │ 结余卡                   │
│ 距离下班还有 03:24:00    │ 今日生存结余 −¥55.26     │
│ 预计 18:00 下班          │ 努力回本 · 报价时间       │
│ 今日计薪进度             │ 公式/完整性说明           │
└─────────────────────────┴─────────────────────────┘
┌───────────────────────────────┬───────────────────┐
│ 工位 0001 · 办公室场景         │ 今日分项           │
│ 拍拍他                        │ 工资/A股/基金/黄金 │
│                               │ 住房/车贷/合计     │

- 指标卡两列等宽；320 dp 手机上的上下堆叠在 PC 上改为左右并排。
- 办公室场景直接复用手机端 `OfficeScene`（380 × 238 逻辑坐标），按容器宽度等比缩放；人物、房子、车、行情屏与手机同一套 Dart painter。PC 只改容器和旁边的信息布局，不重画角色。
- 今日分项列表与合计必须可追溯；点击“统计口径”展开说明。
- 页面底部保留一句语气文案；不作为数据来源。

#### 时间卡

| 状态 | 标签 | 主值 | 说明 | 胶囊 |
| --- | --- | --- | --- | --- |
| 工作 | 距离下班还有 | 距本班结束 `HH:MM:SS` | 预计 18:00 下班 · 按排班计薪 | 在岗中 |
| 午休 | 距离下班还有 | 距同一完整班次结束 | 预计 18:00 下班 · 休息中，工资暂停 | 午休中 |
| 上班前 | 距离上班还有 | 距下一班开始 | 09:00 上班 · 预计 18:00 下班 | 未开始 |
| 已下班 | 本班状态 | 已下班 | 18:00 已下班 · 固定支出继续分摊 | 已下班 |
| 休息 | 今日排班 | 今日休息 | 今天没有排班，好好休息。 | 休息日 |
| 未知 | 排班状态 | 排班待确认 | 请在“配置 → 收入与排班”中确认。 | 待确认 |
| 跨夜 | 距离下班还有 | 距次日班次结束 | 预计次日 06:00 下班 · 按排班计薪 | 在岗中 |

主值 40 px 等宽；秒数向上取整；小时至少两位、不以 24 取模；距离超过 99 小时不截断。到结束时刻（左闭右开）立即显示“已下班”，不显示负数或上一阶段。

#### 结余卡

| 领域结果 | 主值 | 标签 | 颜色/说明 |
| --- | --- | --- | --- |
| complete 正值 | `¥194.74` | 暂时领先 | 绿色；可显示正向语气 |
| complete 负值 | `−¥55.26` | 努力回本 | 砖红；负号不省略 |
| complete 零 | `¥0.00` | 白干持平 | 墨色；不显示 `−0.00` |
| partial | 已知小计 | 部分小计 | 中性；紧邻说明缺项 |
| unavailable | 待配置 | 不可计算 | 中性；不显示虚假 0 |
| stale | 可参与结果 | 缓存/陈旧 | 显示真实报价时间 |

公式说明固定为“工资估算 + 投资今日浮动 − 固定支出已分摊”，不把基金能力写成已实现；基金接入后按 `docs/10` 的小计与净值日期展示。

#### 操作

- “手动刷新”：只刷新行情；工资、支出继续按本地时钟计算；失败保留缓存并显示时间。
- “拍拍他”：工作/午休可用，3.2 秒回应；下班、休息、排班未知禁用；不改变指标卡。
- “统计口径”：打开说明层，展示完整精度、分项取整差异与数据来源。
- 点击分项：进入对应配置或账单；点击住房/车贷插画进入账单。

### 4.4 配置页外壳

- 顶部标题“配置”，副标题“改完即时预览，保存后按新版本重算今天”；右上角“保存配置”。
- 四个子页签：收入与排班 / 资产 / 住房与车贷 / 账单。
- 默认两栏：左表单，右 292 px 固定窗预览。
- **资产页例外**：隐藏右侧预览，表格占满内容宽度；浮动固定窗仍可见。
- 预览面板：当前密度缩略图、说明“今天将按新配置重算”、影响条（生效日期、历史版本、账本修订）。
- 保存前校验；非法字段行内提示；保存中按钮显示“正在保存”，禁止重复提交；成功后 toast 并提升账本修订。
- 修改只影响本机草稿/账本；不触发行情请求；不同步手机，直到 v0.1 文件导入导出或 v0.2 局域网同步。

### 5.3 状态矩阵

所有 `HH:mm` 均为工资时区（默认 `Asia/Shanghai`）。工作状态优先取同一时刻的 `DashboardSnapshot.workSession`、`phase` 和 `computedAtUtc`；本班结束用完整班次 `activeSession.endUtc`。

| 状态 | 标签 | 主值 | 说明 | 胶囊 | 进度 |
| --- | --- | --- | --- | --- | --- |
| 工作中 | 距离下班还有 | 距本班结束 `HH:MM:SS` | 预计 18:00 下班 · 按排班计薪 | 在岗中 | 显示 |
| 午休/班内休息 | 距离下班还有 | 距同一完整班次结束 | 预计 18:00 下班 · 休息中，工资暂停 | 午休中 | 暂停，不归零 |
| 上班前 | 距离上班还有 | 距下一班开始 | 09:00 上班 · 预计 18:00 下班 | 未开始 | 0 或实际已计薪 |
| 已下班 | 本班状态 | 已下班 | 18:00 已下班 · 固定支出继续分摊 | 已下班 | 100% |
| 今日休息 | 今日排班 | 今日休息 | 今天没有排班，好好休息。 | 休息日 | 隐藏 |
| 排班待确认 | 排班状态 | 排班待确认 | 请在“配置 → 收入与排班”中确认。 | 待确认 | 隐藏 |
| 跨夜班 | 距离下班还有 | 距次日班次结束 | 预计次日 06:00 下班 · 按排班计薪 | 在岗中 | 显示 |

边界规则：

1. `remaining = max(0, targetUtc − nowUtc)`；展示秒数向上取整；小时至少两位、不以 24 取模。
2. 到达开始时刻立即转班内；到达结束时刻立即转已下班（左闭右开）。
3. 跨夜班持续指向同一完整班次终点；次日时间写“次日 06:00”，同日晚些时候写 `06:00`；主窗日期在午夜切换，倒计时不提前结束。
4. 前台 1 秒更新可见秒数即可；恢复前台、系统改时、排班/时区变更时立即重算；不补播、不累加。
5. 数据不足显示“排班待确认”，不按星期、设备时区或 `now.hour` 猜测。

参考样例：

| 输入 | 预期 |
| --- | --- |
| 09:00–12:00、13:00–18:00，14:36:00 | `03:24:00`，预计 18:00 下班 |
| 同班 12:30:00 | `05:30:00`；午休中，工资暂停 |
| 同班 08:45:00 | `00:15:00`；09:00 上班，预计 18:00 下班 |
| 17:59:59.900 / 18:00:00 | `00:00:01` / `已下班` |
| 22:00–次日 06:00，23:59:30 | `06:00:30`；预计次日 06:00 下班 |
| 22:00–次日 06:00，00:00:00 | 倒计时继续；主窗日期切到次日；班次不提前结束 |

### 5.4 金额、完整性与隐私

金额规则同 `docs/12`：完整精度求和，最后四舍五入到分；`-0.00` 显示 `0.00`；未知不写 0；分项取整差在统计口径中说明。

| 状态 | 固定窗 | 主窗 |
| --- | --- | --- |
| complete | 金额 + 标签 + 语气 + 报价时间 | 金额 + 分项 + 公式 |
| partial | 已知小计 + “部分小计” + 缺项 | 已知小计 + 缺项 + 分项 |
| unavailable | “待配置” + “不可计算” + 配置入口 | 同上 |
| stale | 结果 + “缓存/陈旧” + 真实时间 | 同上 |
| privacy | `¥••••` + “金额隐身” | **不遮蔽**（主动打开的安全区） |

隐私范围：固定窗、配置预览、托盘提示、窗口标题、固定窗无障碍文案。掩码固定四个圆点，不泄露金额位数；金额隐身时状态、倒计时、完整性文字保留。防截图（`SetWindowDisplayAffinity`）为 P1 实验项，不承诺防拍照。

  └─ 先看看示例          → 固定时钟、隔离命名空间、横幅标识 → 退出回原账本
```

- 从零开始只保留 3 步，不照搬手机 6 步；字段与校验和手机一致，资产可跳过。
- 导入前展示月薪、排班总工时、住房方式、资产数量、导出时间；先备份再原子写入；较旧修订不静默覆盖。
- 完成后 30 秒引导：拖动/贴边、置顶、老板键、金额隐身、右键菜单；可跳过，之后在“设置 → 重新观看引导”重看。
- 示例模式不写正式库，退出后恢复原账本或未完成引导。

原型只实现首启入口弹窗；完整引导流程为设计稿，生产版实现时需补草稿恢复和原子提交。

## 8. 数据与状态映射

| UI | 来源 | 规则 |
| --- | --- | --- |
| 倒计时 | `WorkSessionContext` / `WorkSessionInfo` | 同一 `nowUtc`；完整班次终点；左闭右开；向上取整秒 |
| 工作阶段 | `DashboardSnapshot.phase` / `workSession` | 不在 UI 另判星期或小时 |
| 结余 | `DashboardSnapshot.total` | 完整精度求和后取分；未知不写 0 |
| 分项 | wage/stock/fund/gold/housing/car/principal/interest/rent | 逐项保留已知/未知状态 |
| 完整性 | `DashboardSnapshot.completeness` | complete / partial / unavailable |
| 报价时间 | `quotesAsOf` | 不把 `computedAt` 当报价时间；基金只有日期时 `quotesAsOf=null` |
| 基金日期 | `fundNavDate` | 与净值成对；无净值不伪造 |
| 账本修订 | `ledgerRevision` | 导入、保存、隐私、删除时提升；固定窗拒绝旧修订 |
| 显示模式 | `homeMetricsMode` | `both` / `time` / `balance`；仅本地偏好，不提升账本修订，不清空账本以外的影响 |
| PC 窗口偏好 | 本地 `pc_preferences` | 密度、位置、置顶、透明度、穿透、锁定、自启、热键、夜间降亮、隐私默认 |
| 隐私 | 本地开关 + 快照 privacy | 固定窗/预览/托盘/标题/无障碍遮蔽；主窗可见 |
| 导入 | `.fjob` bundle | 只含账本与配置；不含行情缓存/派生快照；校验后原子写入 |
| 同步 | v0.2 | 只传账本实体；金额不出局域网；冲突不自动合并 |

实现要求：

- PC 测试必须消费 `fixtures/calculation-cases.json`，同一 fixture 与手机输出一致到分。
- PC 不复制工资/分摊/盈亏算法；只做展示映射。
- 显示偏好的读写必须原子、可回滚；连续修改按最后一次写入；迟到结果不覆盖新选择。
- 保存配置携带 `expectedRevision`；冲突提示重新加载，不静默覆盖。
- 示例模式独立命名空间；退出后恢复真实账本与偏好。

## 9. 可访问性

- 键盘可达：导航、表单、固定窗右键菜单、弹窗均可 Tab/方向键操作；焦点环清晰。
- Narrator：固定窗聚焦时读“距离下班还有 3 小时 24 分钟，预计 18 点下班；今日生存结余负 55 元 2 角 6 分，部分小计”；不逐秒自动播报。
- 200% 系统缩放：卡片增高、文字换行、不裁切负号/精度；S 档可切 M 档；配置表单改为单列。
- 对比度：正文与纸面 ≥ 4.5:1；状态不只靠颜色，配文字/图标。
- 低动效：跟随系统“动画效果”设置；固定窗只更新数字，角色静态。
- 命中区：关键按钮 ≥ 32 px（桌面），固定窗悬停控件 22 px 但可点击区域扩到 30 px（实现时）。
