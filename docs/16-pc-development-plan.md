# PC 端开发任务清单与执行计划

版本 1.0 · 2026-11-10 · 状态：**开发启动**。目标：交付完整 Windows PC 伴生端，复用手机端账本、计算与视觉资产。

关联：`docs/13`、`docs/14`、`docs/15`、`prototype/pc.html`、`contracts/`、`fixtures/calculation-cases.json`。

## 0. 完成定义（Definition of Done）

PC 端“完整”指同时满足以下条件：

1. **可安装运行**：Windows 10 1809+ / Windows 11 x64；便携 zip 可运行，安装包可安装；有版本号、更新检查和校验和。
2. **同源账本**：本地 SQLite；收入、排班、资产、住房/车贷、账单与手机字段一致；导入/导出 `.fjob`；金额与手机对同一 fixture 到分一致。
3. **固定窗**：S/M/L 三档；置顶、不抢焦点、不进任务栏、可拖拽贴边、位置记忆、金额隐身、老板键、点击穿透、全屏自动隐藏、睡眠恢复。
4. **主窗**：今日、配置、桌面、数据、设置五页；配置实时预览；异常/空/部分/不可用状态完整。
5. **视觉同源**：角色、房车、办公室、硬币、图标、调色板、拍肩/离场动效来自共享 Dart 包；不使用截图或原型 Canvas 作为生产素材。
6. **行情与完整性**：只发标的 ID；报价时间、净值日期、缓存/陈旧、部分小计、不可用状态正确；不生成随机价格。
7. **隐私**：金额不进日志、标题、托盘提示；固定窗隐身覆盖预览与无障碍文案；主窗为主动打开的安全区。
8. **测试与发布**：共享层/手机/PC 测试通过；`flutter analyze` 无问题；Windows CI 产出 zip；真机走查记录完整。
9. **不破坏手机**：手机端 172 个测试保持通过；双卡、场景、拍肩、离场无视觉回归。

首版不包含：云账号、云同步、银行/券商自动同步、交易流水、多用户、macOS。

### 目标

### 子任务

| ID | 子任务 | 验收 |

| PC0-06 | 托盘 | 托盘图标、菜单、显示/隐藏、退出；关闭主窗不退出进程 |
