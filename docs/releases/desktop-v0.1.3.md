# desktop-v0.1.3 · 同一 Wi-Fi 对码互传

发布日期：2026-11-12 · Tag：`desktop-v0.1.3` · 版本 `0.1.3` · 平台：Windows 10 1809+ / 11 x64。

从 `desktop-v0.1.2` 可直接覆盖安装，账本与显示设置保留。

## 新增

- **数据页「同一 Wi-Fi 直传」**：
  - 「从手机接收」：输入手机屏幕上的地址与 12 位配对码，拉取手机账本；收到后显示与文件导入相同的摘要预览，确认后才写入，导入前自动备份。
  - 「发送到手机」：输入地址与配对码，把本机账本推送到手机；手机端核对并确认导入。
- 传输内容 AES-256-GCM 加密，密钥由配对码经 HKDF-SHA256 派生；不经过互联网、不写日志。
- 手机始终是会话宿主，PC 只发起出站连接，不触发 Windows 防火墙入站提示。
- 一次性会话：成功一次、10 分钟超时或连续 5 次错码后结束。

## 内部

- 新增共享包 `packages/lan_transfer`（与手机同源）；PC 端 37 项测试通过，含 LAN 地址/配对码表单校验。
- 保留 v0.1.2 的手动配置可用性修复、v0.1.1 的托盘/最小化修复。

## 未验证

- 真实双设备（手机 Wi-Fi + 电脑同一路由器）未在本轮复测；PC 客户端通过共享包回环测试与手机模拟器联调验证。
- 路由器 AP 隔离/访客网络、手机锁屏或系统杀后台会中断会话。
- 完整局域网同步（持久配对、双向合并、冲突 UI）仍按 PC6/v0.2 规划。
- 200% 缩放、多显示器、Narrator 未复测。

## 校验

`SHA256SUMS` 随 Release 提供，包含安装包与便携 zip；设置页「检查更新」使用同一 SHA-256 校验安装包。
