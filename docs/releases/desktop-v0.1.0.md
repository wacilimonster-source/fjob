# desktop-v0.1.0 · PC 伴生端首个安装包

发布日期：2026-11-11 · Tag：`desktop-v0.1.0` · 版本 `0.1.0` · 平台：Windows 10 1809+ / 11 x64。

PC 端首个安装包版本：工位固定窗 + 配置台，复用手机账本与计算。下载 `FJOB-Setup-0.1.0.exe` 双击安装（当前用户安装，无需管理员，装到 `%LOCALAPPDATA%\Programs\FJOB`）；便携版可解压 `fjob-desktop-0.1.0-win-x64.zip` 直接运行。账本数据保存在 `%APPDATA%\FJOB`，卸载不会删除。

## 固定窗

- S / M / L 三档：220×76 数字条、320×220 便签卡、420×390 工位窗；切换锚定右下，位置按显示器记忆并在重启后恢复。
- 视觉层级：下班时间为主核心（M/L 倒计时 40px，M 档含迷你计薪进度），今日生存结余为次核心（金额 34px，语气句只在主窗显示）。
- 状态矩阵覆盖工作/午休/上班前/已下班/休息/排班待确认/跨夜；部分小计、不可用与陈旧报价有明确标记。
- 金额隐身（固定窗遮蔽、主窗可见）、老板键 `Ctrl+Alt+H`、点击穿透、锁定位置、纸面透明度、减少动效。
- 右键菜单：打开主窗 / 金额隐身 / 点击穿透 / 隐藏到托盘；双击固定窗拉起主窗。

## 主窗（四页）

- 配置：收入与排班、资产、住房与车贷、账单；右侧固定窗实时预览。
- 桌面：显示项（都显示/只看下班/只看结余）、密度、隐私与窗口行为、窗口控制。
- 数据：`.fjob` 导入/导出、最近备份恢复、清空。
- 设置：版本、来源、数据目录与更新。
- 今日页已按产品决定移除；首次启动欢迎面板提供「从手机导入」与「从零开始」。

## 检查更新

设置页「检查更新」读取 GitHub Releases 的 `desktop-v*` 通道（与手机 `v*` 通道隔离，不会误装 APK）：只选中带 Windows 安装包且提供 SHA-256 的 Release；镜像优先、直连兜底；下载后校验 SHA-256，通过后才可运行安装程序。检查失败时保留当前版本。

## 安装与卸载

- 安装：`FJOB-Setup-0.1.0.exe`，当前用户安装，无管理员权限；可选桌面快捷方式。
- 卸载：设置 → 应用 → 今日又白干 → 卸载，只移除程序文件，账本与显示设置保留。
- 便携版：解压即用；数据目录同为 `%APPDATA%\FJOB`。

## 已知边界

- 未做代码签名，首次运行可能出现 SmartScreen 提示。
- 真实行情来源（东方财富公开接口）为 developmentOnly，展示许可仍为发布门禁。
- 全屏自动隐藏、托盘菜单逐项点击、200% 缩放/键盘全流程/Narrator 未在真机验收。
- 局域网同步（PC6）、macOS、自动安装（当前为检查+下载+用户确认运行）不在本版范围。

## 校验

`SHA256SUMS` 随 Release 提供；设置页检查更新也以同一 SHA-256 校验安装包。
