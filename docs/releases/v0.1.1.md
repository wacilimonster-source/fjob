# v0.1.1 · 固定浅色纸感（开发预览）

发布日期：2026-11-04 · Tag：`v0.1.1` · 包名：`cn.fjob.todayagain` · versionName `0.1.1`，versionCode `2`。

本版只调整主题与界面设置：应用固定使用奶油纸感浅色，不再跟随系统深色，也不再提供主题切换。其余功能、计算口径与 v0.1.0 一致。

## 变更

- 移除“随系统 / 浅色 / 深色”主题选择，设置页改为只读的“纸感浅色”说明。
- 即使设备处于深色模式，应用仍显示浅色纸面；状态栏与导航栏图标固定为深色，保证可读性。
- 删除深色配色与 `ThemeMode` 分支，手绘场景、账单卡片和小部件预览始终使用同一套浅色 token。
- 新增回归测试：系统深浅色为 dark 时，应用 `Theme.brightness` 仍为 light，背景为 `#F7F2E9`。
- 更新产品与验收文档中关于“主题随系统 / 暗色验收”的条目。
