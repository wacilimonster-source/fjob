# v0.1.10 · 首页双核心指标与基金持仓（仅 APK）

发布日期：2026-11-09 · Tag：`v0.1.10` · versionName `0.1.10` / versionCode `1000 + CI RUN_NUMBER` · 包名：`cn.fjob.todayagain`。

依据 [首页双核心指标设计与开发交接](../12-design-home-dual-metrics.md) M8-HOME 实施，并包含工作区中已完成的 [国内基金持仓](../10-design-domestic-fund-holdings.md) M7-FUND 改动。

## 新增

- **首页双核心指标**：打开首页先看到“距离下班还有”和“今日生存结余”。默认双卡，时间卡在上、结余卡在下；两卡之间只有两枚窄纸夹作衔接，单卡时不保留空位。
- **三种首页显示**：“首页显示”入口可展开“都显示 / 只看下班 / 只看结余”。选择立即预览并保存，面板保持展开；入口在三种模式下始终可找到。
- **下班时间状态**：工作中、休息中、上班前、已下班、今日休息、排班待确认六种状态；倒计时精确到秒，向上取整，小时不按 24 取模；跨夜班显示“次日 06:00”；恰好 18:00 立即显示“已下班”。
- **今日计薪进度**：时间卡内显示 `今日计薪 4.6 / 8.0 小时`；休息中工资暂停但倒计时继续；休息日与排班未知隐藏进度。
- **结余完整性**：完整金额按正负显示“暂时领先/努力回本”；部分数据标“部分小计”并列出缺失项；核心配置不可用显示“待配置/不可计算”；陈旧缓存标“缓存/陈旧”并显示真实报价时间。部分小计不会被推断为最终盈亏。
- **基金持仓**：场外基金录入、日终净值与收益、已知基金小计与缺项说明；首页、资产页和 Android 小部件 v2 同步。基金不会被塞进股票字段。
- **本地显示偏好**：`homeMetricsMode` 保存在独立 `ui_preferences` 表，不提升 `ledgerRevision`、不请求行情、不发布小部件；清空账本同时清除，下次默认双卡；示例模式使用内存选择，退出后恢复真实偏好。

## 修复

- 完整班次在恰好结束时刻（如 18:00:00 或跨夜 06:00:00）被短暂判为休息日的问题；结束边界改为左闭右开。
- 结余卡不再把 `computedAt` 当作报价时间；陈旧/模拟报价使用 `quotesAsOf` 并显式标记。
- 时间卡不再和拍肩按钮挤在同一行；拍肩入口移到场景下方，倒计时不被回应覆盖。
- 基金已知小计与整体不完整同时显示，缺一只基金不会抹掉另一只的已知浮动。

## 边界与规则

- 切换首页显示只写本地界面偏好：不改工资、支出、投资计算，不改 `ledgerRevision`，不请求额外行情，不重置拍肩/离场状态。
- 连续快速选择按用户最后一次选择顺序串行写入；迟到的旧成功/旧失败不覆盖新选择；最终写入失败回滚最近成功模式并提示“显示设置没存上，请重试”。
- 示例模式不写正式账本或偏好；重新走引导保留选择；未知枚举安全回退双卡。
- 小部件快照契约与原生代码未改；首页重排不新增数据采集、日志或网络参数。
