# v0.1.4 · 持仓录入自动识别代码与名称

发布日期：2026-11-05 · Tag：`v0.1.4` · 包名：`cn.fjob.todayagain` · versionName `0.1.4`，versionCode `1007`。

本版改进“添加持仓”：

- 不再要求选择“沪/深/京”。输入 6 位代码后按前缀自动识别：
  - `6xxxxx` → 沪市（含 688 科创板）
  - `0xxxxx`、`3xxxxx` → 深市（含创业板）
  - `4xxxxx`、`8xxxxx`、`92xxxx` → 京市
- 识别后通过行情客户端查询名称并自动填入；名称仍可手动修改。
- 查询不到时保留已识别市场，提示“名称待联网确认”，用户可自行填写。
- 持仓表单改为可滚动并启用安全区，键盘弹出时名称、股数、成本仍可正常点按输入（修复此前名称无法输入的问题）。
- 新增 `instrument_directory` 缓存（数据库 schema v2），持仓列表、编辑表单和重走引导都会显示名称；旧 v1 数据库自动升级。
- 当前 fixture 目录内置常见代码名称；接入行情网关的 `/v1/instruments/search` 后可返回完整目录。未知代码不会被编造名称。
