# v0.1.3 · CI 签名发布

发布日期：2026-11-05 · Tag：`v0.1.3` · 包名：`cn.fjob.todayagain` · versionName `0.1.3`，versionCode `6`（本次由 `GITHUB_RUN_NUMBER` 生成）。

本版应用功能与 v0.1.2 相同（固定浅色纸感、应用内检查更新与下载安装）。区别是发布流程：Android 发布密钥已写入 GitHub Actions Secrets，tag 触发的 `android-release` 工作流完成签名 APK/AAB 构建，产物再附加到本 Release。

## 变更

- 发布工程：`android-release` 工作流从 tag 构建并签名，签名密钥读取 `ANDROID_KEYSTORE_BASE64`、`ANDROID_KEYSTORE_PASSWORD`、`ANDROID_KEY_ALIAS`、`ANDROID_KEY_PASSWORD` 四个 Secrets。
- 本次 tag 构建的 versionCode 为 `6`，高于 v0.1.2 的 `3`，可直接覆盖升级。
- 后续 tag 构建将使用 `1000 + run_number` 保持 versionCode 单调递增。
- Secrecy：keystore 只存在于 GitHub Actions Secrets 与本机 `.release/`，仓库不包含任何签名材料。
