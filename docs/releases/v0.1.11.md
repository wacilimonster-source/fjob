# v0.1.11 · 手机与电脑交换账本（仅 APK）

发布日期：2026-11-11 · Tag：`v0.1.11` · versionName `0.1.11` / versionCode `1000 + CI run` · 签名沿用既有 CI keystore，可直接覆盖安装升级。

## 新增

- **手机与电脑交换账本**：设置 → 数据 → 「手机与电脑交换账本」。
  - 导出 `.fjob`：只含账本与配置（收入、排班、资产、住房/车贷、账单、设置），不含行情缓存、快照、日志或设备标识。
  - 导入预览：月薪、时区、本月排班工时、资产项数、房贷/车贷、账单月份；可选「替换本机账本」或「合并」。
  - 导入前自动备份；校验和校验；同账本旧修订拒绝；原子写入，失败不部分落库。
  - 首次引导欢迎页新增「已有账本？导入 .fjob」入口。

## 内部

- **共享引擎重构**：账本模型、`.fjob`、格式化、首页显示模型、存储（SQLite schema v6）与行情客户端抽到 `packages/ledger_model`、`ledger_store`、`market_data`、`fjob_ui`，与 PC 端同源；手机端删除重复实现，行为不变。
- 手机端 176 项测试通过（1 项既有跳过），`flutter analyze` 无问题；finance_core 110、ledger_model 77、ledger_store 13、market_data 65、fjob_ui 35 全过。

## 兼容

- 数据库 schema 与 v0.1.10 兼容，升级不迁移丢失；签名与之前版本一致（CI 使用同一 keystore），应用内更新不会出现签名不一致。
- 旧版本可通过应用内「检查更新」或本 Release 的 APK 升级。

## 校验

`SHA256SUMS` 随 Release 提供；应用内更新同样校验 SHA-256 后才交给系统安装器。
