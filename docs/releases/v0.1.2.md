# v0.1.2 · 应用内检查更新与下载安装

发布日期：2026-11-04 · Tag：`v0.1.2` · 包名：`cn.fjob.todayagain` · versionName `0.1.2`，versionCode `3`。

本版新增“检查更新 / 下载 APK / 调起系统安装器”，并保持固定浅色纸感。

## 新增

- 设置页新增“更新”分组：显示当前版本、检查 GitHub Releases、展示版本说明与安装包大小、下载进度与取消。
- 语义化版本比较；忽略草稿与没有 APK 的发布；按 `arm64-v8a / armeabi-v7a / x86_64` 优先选择分架构安装包，否则回退 universal APK。
- 下载通过 HTTPS 流式写入应用缓存，按 GitHub 提供的 `sha256` 摘要与文件大小校验，校验失败立即删除。
- 通过 Android `FileProvider` 把缓存内的 APK 交给系统安装器；通道只接受 `cache/updates` 下的文件，避免任意路径安装。
- Android 8+ 检测“安装未知应用”授权，并提供跳转设置入口；下载可取消。
- iOS 显示版本检查结果，但明确提示通过 TestFlight/App Store 更新，不直接安装 APK。
- 权限：新增 `REQUEST_INSTALL_PACKAGES`；更新检查只访问 GitHub Releases，不上传任何工资、持仓或账单数据。
