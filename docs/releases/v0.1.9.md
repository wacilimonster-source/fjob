# v0.1.9 · 拍拍他与下班离场（仅 APK）

发布日期：2026-11-06 · Tag：`v0.1.9` · versionName `0.1.9` / versionCode `1012`（CI run #12，`1000 + RUN_NUMBER`）· 发布日期：2026-11-06。

依据 [docs/09-design-comfort-and-clock-out.md](../09-design-comfort-and-clock-out.md) SCN-01 至 SCN-05 实施。

## 新增

- **拍拍他**：工位上（工作或午休）点击按钮或人物头肩，播放 3.2 秒拍肩、抬眼、腮红、放松肩膀的完整回应；文案池温柔/犀利各三条按接受次序循环，语气在一句回应内锁定；单次轻触觉；播放中连点被忽略，不叠加不延长。
- **下班离场**：真实班次结束（前台可见且首次观察到结束不超过 2 秒）播放 2.2 秒停手、关屏、起身、提包走出，随后为空工位稳态；下班后再次进入 App 直接显示空位，不补播。
- **空工位状态**：上班前「还没到岗」、下班「已下班」、休息日「今日休息」、排班未知「排班待确认」四种便签与禁用按钮；场景语义描述随状态播报。
- **跨夜班**：22:00–02:00 等跨午夜班次在午夜后仍在岗、02:00 才离场；02:00 至当晚下一班之间显示「已下班，下一班 22:00」。
- **减少动效**：系统或应用内开启后，拍肩立即呈现静态抬眼回应（保留 2400ms），下班直接切空位。
- **桌面小部件**：大号小部件按快照 scene 与房/车配置显式选择 12 张预生成场景图之一；下班/休息日/未知一律空工位，修复旧静态图残留人物的问题；快照契约新增可选 `showHousing`/`showCar`。

## 修复

- 盈利笑脸时点击人物反馈不明显的旧问题（回应表情独立于盈亏天气）。
- 点击房子、汽车或空白不再触发安慰（旧版整幅场景可点）。
- 安慰文案不再占用主卡财务说明位，移入场景下方固定反馈区。

## 边界与规则

- 拍肩与离场是纯展示瞬态：不写数据库、不改变账本修订、不请求行情、不发布小部件快照；同帧时钟下拍肩前后金额完全一致（PAT-T08 有自动化断言）。
- 页面隐藏、切后台、切页、路由覆盖、时钟跳变、排班修订一律取消瞬态并回到稳态，不补播。
- 真实可见性（前台 + 选中页 + 无路由覆盖 + 场景在视口内超过一半）才允许播放离场；错过的结束直接显示稳态。
