# v0.1.5 · 大小周排班（Android / APK）

发布日期：2026-11-05 · Tag：`v0.1.5` · 包名：`cn.fjob.todayagain` · versionName `0.1.5`。

## 大小周

- 引导第 2 步新增“固定星期 / 大小周”切换。
- 小周核心工作日可在周一至周五内自定义；大周在核心日之外增加一个额外工作日。
- 额外工作日支持周六/周日单选，默认周六；大周沿用同一上下班时间与午休。
- 默认“本周是大周”，可直接切换为本周小周；按自然周（周一为周首）交替。
- 未来四周预览与本月计薪天数/小时实时重算。
- 核对页显示“大小周 · 本周大周/小周 · 额外周六/周日”；首页工资备注标注大小周。
- 重走引导修改排班时，生效日期必须是周一，避免一周被两套配置切开；初次入职不受此限制。
- 月分母、今日工资、跨夜班、日期覆盖与版本分段均使用同一计算引擎；整月配置不变时累计仍等于月薪。

## 存储

- `schedule_versions` 新增 `alternation_json`（schema v3），保存小周/大周模板与锚点。
- 旧 v1/v2 数据库自动升级，固定周配置与历史不变。

## 范围收敛

- 删除 `apps/mobile/ios/`、iOS WidgetKit 源码与 `ios-release.yml`。
- CI 移除 macOS/iOS 模拟器任务；发布只构建并分发 **APK**，不再产出 AAB。
- 历史 Release 中的 AAB 保留，新版本不再上传。
