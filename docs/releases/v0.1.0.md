# v0.1.0 · 开发预览（M0–M5）

发布日期：2026-11-04 · Tag：`v0.1.0` · 包名：`cn.fjob.todayagain` · versionName `0.1.0`，versionCode `1`。

这是“今日又白干”的第一个可安装开发预览版，覆盖交付包中的 M0–M5：领域计算、六步引导、本地账本、四个主页面、Android 小部件、行情网关（fixture）以及 iOS 源码。真实行情、iOS 扩展 target 接线、商店签名与上传仍未完成。

## 安装

- Android 8.0（API 26）及以上。
- 下载 `fjob-0.1.0-universal.apk` 侧载安装；如果需要上架或内部测试轨道，使用 `fjob-0.1.0.aab`。
- 首次打开进入六步入职引导；资产与固定支出均可跳过。
- 行情与交易日历当前为模拟数据，界面、快照和设置页均有明确标注。

## 功能

- 工资按当月排班计薪秒数分摊，前台约 250ms 重算，不逐 tick 累加。
- 排班支持周模板、午休、跨夜班、日期覆盖；月薪 0 允许空排班。
- 固定支出按自然日与真实日长分摊；住房房贷/房租/暂无互斥，车贷独立；本金未知与真实 0 区分。
- A股多持仓与按克黄金，今日/持有盈亏、休市与跨交易日基准、黄金参考交易日口径。
- 六步引导、草稿恢复、`setupSessionId` 幂等提交、单事务写入、修订冲突提示。
- 首页手绘办公室、天气与盈亏状态、硬币流向、午休/下班/休息/安慰状态；暗色与减少动效。
- Android RemoteViews 小部件：三档密度、隐私遮蔽、深链、WorkManager 30 分钟刷新；快照由 Dart 预计算。
- 行情网关：fixture 适配器、缓存、single-flight、限速与 429、交易日历；公开候选源默认停用。

## 隐私

个人工资、持仓数量与成本、租金与贷款金额只保存在应用沙盒。行情请求仅包含标的 ID；清空账本会删除配置、草稿、行情缓存并发布 tombstone 快照。
