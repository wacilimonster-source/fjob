# 交互、首次引导与视觉规范

版本 0.2 · 2026-11-04。

## 1. 原型使用与规则优先级

`prototype/index.html` 是可点击参考，包含首次入职、四个主页面、修改持仓、住房方式、月供、小部件预览及示例模式。原型的字体、间距、配色、造型和页面反馈是视觉参照。业务规则以产品需求和数据契约为准。

原型固定在 2026 年 11 月演示，仅含一个A股示例与一笔黄金，用同日上下班和手填排班天数代替完整日历。正式实现应补齐多持仓、跨夜班、日历、真实行情和进程恢复。原型示例金额不可作为首次真实填写的默认值。

## 2. 视觉语言

整体为丧萌纸感小剧场。奶油色背景、深灰绿色粗轮廓、扁平低饱和色块、略不规则的边缘。角色头大身小、黑眼圈、下垂眼皮、松垮领带。表情表现疲惫与偶尔的小开心。

房子采用歪歪屋顶、门、少量大窗和一扇亮灯窗。车采用圆润侧面、两个圆轮、两块车窗和简单车灯。两者沿用角色、桌椅的线宽与配色，在办公室、账单封面和小部件统一复用造型。

| Token | 浅色 | 用途 |
| --- | --- | --- |
| paper | #F7F2E9 | App 底色 |
| panel | #FFFDF7 | 内容纸面 |
| ink | #323A32 | 字与轮廓 |
| muted | #686E61 | 辅助文字 |
| line | #D5D6C8 | 分隔 |
| soft | #E9EDDF | 办公室墙面与选中底色 |
| yellow | #F2DFAC | 便签、灯光、硬币 |
| rose | #F0D2C5 | 椅子、小车、房顶 |
| negative | #AD4736 | 负值 |
| positive | #46644E | 正值 |

本版固定使用浅色纸感，不提供深色主题；色值为设计初值，开发时验证文字对比度。涨跌用符号、文字和表情辅助，允许用户切换证券红涨绿跌显示偏好，默认综合金额正绿负砖红。大数字使用等宽数字字形，正文使用系统中文字体。

参考手机内容宽约 390dp。左右内边距 18dp，卡片内边距 16dp，间距以 4dp 为基础。页面标题 25sp，正文 14sp，辅助文字 12sp，综合金额默认 42sp。空间不够时先降低数字字号至 28sp，再增加行高或使用紧凑货币单位展示并保留完整数值可访问文本。

轮廓约 1.5—2dp，人物及场景主线约 2dp，背景线更轻。按钮、卡片和图案采用相近圆角，允许绘制边缘的轻微偏差。动画中几何不规则由确定性参数产生，避免每次重绘随机抖动。

## 4. 首次引导文案表

| 步骤 | 标题 | 主按钮 | 关键信息 |
| --- | --- | --- | --- |
| 欢迎 | 入职手续，生活替你准备好了。 | 办理入职 | 工资排班必填，其他按需 |
| 收入 | 每个月，生活给你多少安慰费？ | 下一步，生活还在等 | 到手金额可为零 |
| 作息 | 你几点上线，又几点归还自己？ | 给工资安排出场时间 | 排班时区、午休和跨夜 |
| 资产 | 钱包还在哪几个战场？ | 支线已登记，继续 | 没有资产可直接跳过 |
| 固定支出 | 登记生活的固定嘉宾。 | 看看我的开局配置 | 房贷/房租/暂无、独立车贷 |
| 核对 | 这就是你的开局配置。 | 配置已阅，开始求生 | 可回改、隐私、估算说明 |

输入错误采用明确说明并附轻微戏谑。月供本金过大时显示“本金超过了本月月供，请核对账单。生活暂时还没学会这个算法。”网络错误显示“报价暂时没赶上，工资还在走。当前显示截至 HH:mm 的缓存。”

避免用穷、失败、废物等词评价用户。语气轻度默认，可选“再狠一点”。不对用户的真实盈亏和个人处境做价值判断。

## 5. 场景动画规格

业务状态驱动动画，动画不参与账本计算。独立组件包括 `Worker`、`Desk`、`House`、`Car`、`Coins`、`Weather`、`MarketScreen`。首版使用 Flutter CustomPainter 与 AnimationController，静态关键帧可离屏渲染为原生小部件图。

| 状态 | 触发 | 视觉与节奏 |
| --- | --- | --- |
| working | 有效计薪时段 | 敲键盘约 2Hz，轻微呼吸约 4秒，硬币每 2—4秒一批 |
| break | 午休等非计薪间隔 | 手离键盘，杯子轻冒气，工资硬币停止 |
| offDuty | 当日班次结束 | 小人瘫坐，固定支出标签保持 |
| restDay | 当日无排班 | 空椅子或便签“人呢？”，账单保持 |
| loss | 完整综合值小于 0 | 下垂眼皮、窗外细雨、行情屏下行 |
| gain | 完整综合值大于等于 0 | 轻微微笑、窗外小太阳 |
| unknown | 综合值不完整 | 窗外多云、行情屏显示等待，避免暗示确定盈亏 |
| comfort | 点击人物 | 约 5秒短暂微笑与文字“先喘口气” |
| reduceMotion | 系统减少动效或设置低动效 | 静态关键帧，数字直接更新 |

工作时段与盈亏是两个正交状态，`comfort` 临时覆盖表情，结束恢复最新状态。报价状态未知覆盖盈亏天气。切换状态 200—350ms，已有动画平滑转场，禁止因每次金额变化重启整段动画。

硬币流向只对有效支出项可见。用于表达收支关系，数量与速度有上限，不按金额比例无限增加。后台和屏幕不可见时释放 Ticker。首版默认静音。

## 6. 小部件布局

小号优先数字、角色表情及数据时间。中号增加工资、投资、固定支出三项。大号增加静态办公室与住房/车贷分项。原生尺寸以平台系统给出的可用区域适配，中文标签优先完整展示。

冻结报价、离线、待配置、金额隐藏均有独立预览。锁屏等更小表面作为后续扩展。原生小部件展示明确的快照时间，点击总额跳首页，点击住房账单跳对应支出页。

## 7. 交互完成定义

每个按钮都需要定义成功、进行中、失败及重复点击行为。保存中按钮显示“正在登记”，输入保留。底部导航保留页面编辑状态，离开未提交表单时提示保留草稿或放弃。

视觉验收同时检查首页、引导、房租、房贷、零支出、大额金额、320dp、系统大字与减少动效。房子和车的轮廓、色块、线宽需与办公室一致，作为高优先级截图回归项。
